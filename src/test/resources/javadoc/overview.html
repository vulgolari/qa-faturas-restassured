Projeto de Testes - Sistema de Gerenciamento de Faturas

Este projeto contém a automação de testes para o sistema de gerenciamento de faturas. Os testes foram desenvolvidos utilizando Java, JUnit 5 e Rest Assured.

Estrutura do Projeto

  • base: Classes base para os testes
  • model: Classes de modelo para representar os objetos do sistema
  • service: Classes de serviço para encapsular as chamadas à API
  • test: Classes de teste com os cenários implementados

Cenários de Teste

  • Criação e gerenciamento de contratos
  • Geração e controle de faturas
  • Processamento de pagamentos
  • Controle de vencimentos e multas
